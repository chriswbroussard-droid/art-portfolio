# Images Directory

This directory contains images for the art portfolio website.

## Structure

- `placeholder*.svg` - Placeholder images for gallery items
- `artist-photo.svg` - Artist profile photo
- `favicon.svg` - Website favicon (located in root directory)

## Adding Your Own Images

1. Replace the placeholder images with your own artwork
2. Maintain consistent naming for easy reference
3. Recommended image sizes:
   - Gallery images: 800x600px or similar aspect ratio
   - Artist photo: 400x400px (square format works best)
   - Favicon: 32x32px or 64x64px PNG

## Image Optimization

For better website performance:
- Compress images before uploading
- Use appropriate file formats (JPEG for photos, PNG for graphics with transparency)
- Consider using WebP format for modern browser support
